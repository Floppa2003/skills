# Поиск одежды и обуви

Результат поиска — точная карточка с выбранным вариантом, понятным продавцом и проверенными условиями. Названия кнопок ниже служат ориентирами: расположение, язык и доступные функции проверять в текущем приложении.

## 1. Задать цель и маршрут

Собрать бренд, модель, артикул производителя/SKU, код цвета, исходную ссылку и 2–3 чистых фото; состав, мерки, допустимое состояние; бюджет, город и срок получения. Внутренний номер российского маркетплейса может отличаться от артикула производителя. Недостающие данные не мешают начать с фотографии или короткого запроса.

| Цель | Первый маршрут | Что уточнить |
| --- | --- | --- |
| Подтверждённый оригинал | Китайский сайт бренда → указанные им магазины; затем точный SKU | Авторизацию продавца, вариант, документы и условия заказа |
| Точная брендовая обувь | Официальный канал; дополнительно Dewu / 得物 | Расцветку, мужскую/женскую/детскую линейку, цену нужного размера, канал исполнения и проверку |
| Заявленный экспортный ассортимент | Taobao: фото/SKU, 出口俄罗斯, 俄单, 外贸 с категорией | Происхождение конкретной вещи; экспортное описание само его не подтверждает |
| Похожий фасон | Taobao: фото + категория/материал; дополнительно 1688 | Состав, конструкцию, комплект, цену выбранного количества и минимальную партию |
| Китайская самостоятельная марка | Rednote / Xiaohongshu → имя бренда → магазин; каталог Eddy Brands | Точное написание, исходную ссылку, ассортимент и покупательские фото |
| Снятая с продажи или подержанная вещь | Китайский Xianyu / 闲鱼 | Реальный экземпляр, состояние, продавца и условия возврата |

Начать можно с одной площадки и переводчика скриншотов. Оплату и доставку выбирать после нахождения кандидатов. [1688](https://home.alibabagroup.com/en-US/about-alibaba-businesses-1941299332078632960) ориентирована на оптовые предложения: наличие товара там и значки 超级工厂 / 实力商家 / 真实工厂 не подтверждают авторизацию бренда. У 1688 проверять 一件起批 / 两件起批 и цену своего количества.

## 2. Найти точную вещь и расширить выдачу

1. **Артикул.** Взять полный SKU и цвет с сайта бренда, бирки или коробки; искать латиницей, затем по точному названию модели. Сверять найденные варианты по конструкции и маркировке. Код в чужом заголовке сам по себе не подтверждает бренд.
2. **Изображение.** Убрать интерфейс, надписи и посторонние предметы. При слабом результате попробовать другой ракурс или характерную деталь. Различать четыре входа:

| Исходник | Действие | Проверка перехода |
| --- | --- | --- |
| Фото вещи | Камера / поиск по фото → 相册 | Откроются кандидаты по сходству; проверить модель и вариант |
| Фото открытой карточки | Открыть фото → меню → 找相似 | Это поиск похожих; 保存图片 означает сохранение изображения |
| Картинка Taobao с кодом товара | Камера → 相册 → картинка | Установить, открылась ли нужная карточка, магазин или обычная выдача |
| QR магазина из PDF/альбома | Выделить один QR крупно → 扫码 → 相册 | Должна открыться витрина; вся страница/коллаж может дать похожие товары |

Маршруты: [поиск похожих](https://t.me/lubchinskaia/788), [картинка с кодом](https://t.me/lubchinskaia/590), [QR магазина](https://t.me/shopping_in_chinaaa/323?comment=445).

3. **Китайский запрос.** Взять категорию из [словаря](chinese-lexicon.md). Добавлять по одному признаку: пол, материал, фасон, бренд или экспорт. При слишком узкой выдаче убрать последнее уточнение. Для образов подходят 搭配套装, 通勤套装, 店主搭配, 实拍搭配, 博主同款, 小个子穿搭; комплектность проверять отдельно.
4. **Заголовок найденной вещи.** Скопировать китайский заголовок подходящей карточки, перевести для понимания, убрать лишние признаки и повторить поиск по очищенной китайской строке. Обратный перевод не обязателен. [Пример приёма](https://www.youtube.com/watch?v=05S8ORIXJHc).
5. **Другие площадки.** Повторить поиск по SKU/фото на 1688 или Pinduoduo и сравнить реальные параметры. Одинаковое рекламное фото не устанавливает одного изготовителя, ткань, партию или качество.

## 3. Развить поиск через магазин и каталог

В карточке изучить галерею и 详情 / 宝贝详情: состав, маркировку, бирки, швы, фурнитуру, подкладку и мерки. Маскированные названия вроде `lim*e` или `ZA*RA` полезны для поиска, но не для подтверждения происхождения.

Перейти 进店逛逛 → 全部宝贝 / 宝贝; посмотреть 新品 / 上新 / 上新日历, категории и сортировки 价格 / 销量. Для распродажи искать 分类 → нужный отдел → 折扣季 → категорию. [Пример навигации](https://t.me/lubchinskaia/1651). Сохранять устойчивый адрес/ID магазина и конкретные карточки: короткая ссылка или QR могут перестать работать.

Для самостоятельных марок:

- [Eddy Brands](https://www.eddyzzlz.com/brands): отфильтровать пол, стиль одежды или аксессуаров → открыть марку → кнопку `Taobao`. [Eddy Bought](https://www.eddyzzlz.com/bought-links) даёт отдельные товарные ссылки. Проверять конечный адрес, наличие и продавца; часть ссылок ведёт через партнёрского посредника.
- Rednote / Xiaohongshu: найти образ → прочитать подпись и имя дизайнера/марки → сверить написание на бирке/витрине → найти исходный магазин. Ролик и каталог дают поисковую зацепку, а не гарантию качества.
- Использовать объединённые имена, ID и ссылки из [каталога магазинов](stores-and-catalogues.md). Рекомендация посредника автором подборки не делает его обязательным для покупки.

## 4. Дополнительные инструменты

### Pinduoduo

По [гайду PDD](https://podeshevle.kz/post/ru/pinduoduo-guide):

| Задача | Путь / условие |
| --- | --- |
| Сузить выдачу | `Brand`; сортировки `Relevance`, `Sales`, `Price`; `Filter → Price range (CNY) → Confirm`, `Reset` для сброса. Проверять валюту фильтра: диапазон может остаться в CNY при показе цен в тенге |
| Проверить продавца | Магазин → `Store Qualifications`: прочитать сведения и авторизацию. `items sold in our store` — продажи всего магазина |
| Прочитать отзывы | `Item Reviews → See all`; отдельно `Picture`, `Video`, `Latest`, `Follow-up review`; читать текст и повторяющиеся жалобы |
| Найти похожее | Если доступно: фото карточки → появившаяся лупа → похожие предложения. [Объяснение приёма](https://www.youtube.com/shorts/ejEz26igX8w) |

Тематический тег вроде `Hard soles` описывает жалобу на жёсткую подошву, а не все отрицательные отзывы. `Shipping within 48 hours` означает отгрузку, не прибытие в РФ. `百亿补贴`, цвет значка, фильтр бренда и название flagship не заменяют проверки продавца и применимых правил защиты заказа. Казахстанские способы оплаты и доставки не переносить на РФ.

### Xianyu / 闲鱼

Уточнить приложение и регион: [условия Xianyu](https://terms.alicdn.com/legal-agreement/terms/c_platform_service_agreement/20260429095912704/20260429095912704.html) разграничивают китайский 闲鱼 и отдельный клиент Goofish. Искать бренд/SKU + категорию; 全新 / 未使用 — заявленное новое состояние, которое нужно сверить с фото экземпляра. Проверить историю и другие объявления продавца, бирки, дефекты, мерки, поддержку площадки посредником. До оплаты согласовать возврат: он зависит от продавца, правил и обещаний, а не только названия площадки. [Условия защиты покупателя](https://terms.alicdn.com/legal-agreement/terms/platform_service/20220929192101114/20220929192101114.html).

### WeChat и UNIQLO

Для дополнительных фото брать опубликованный магазином деловой 微信 / WeChat ID, сверять его принадлежность продавцу и изучать доступные 朋友圈 / Moments. Видимость может требовать добавления контакта. По фото определить модель/SKU/цвет и найти соответствующую карточку; мерки, комплект, состояние и возврат закрепить на площадке. Добавление контакта и сообщения требуют разрешения пользователя. [Метод](https://t.me/lubchinskaia/1332).

Для UNIQLO начинать с [официально указанного uniqlo.cn](https://www.fastretailing.com/eng/group/strategy/greaterchina.html). [Гайд](https://podeshevle.kz/post/ru/wechat-uniqlo) предлагает открыть фирменное мини-приложение в WeChat, зарегистрироваться в магазине, при доступности войти на сайт через QR/WeChat, выбирать вещи и таблицы размеров в браузере, оплату завершать на телефоне. Проверять принадлежность мини-приложения бренду, доступность входа, корзины, российского номера/карты и своего адреса. Предварительная покупка для просмотра из этого маршрута не следует. [Связь фирменного магазина с WeChat](https://www.fastretailing.com/eng/ir/library/faq20190411.html).

### FindQC

Скопировать URL товара через меню «поделиться» → вставить в [FindQC](https://findqc.com/) → изучить доступные складские QC-фото. [Описание маршрута](https://www.youtube.com/watch?v=tZAdO65HTFM). Проверять модель, вариант, дату и партию фотографий. Это дополнительное сравнение с рекламной галереей: фотографии другого заказа не удостоверяют оригинальность или состояние будущей покупки; отсутствие фото ничего не доказывает.

## 5. Проверить кандидата и зафиксировать результат

Открыть точную карточку и выбрать размер, цвет, материал, комплект, состояние и количество. Проверить наличие/предзаказ и возможность доставки по выбранному адресу. Цена выдачи может относиться к другому варианту, купону, задатку или количеству: 起 — «от», 券后 — после купона, 定金 — задаток, 不包邮 — доставка отдельно, 套装 / 单件 — комплект / отдельный предмет.

| Объект | Что проверить |
| --- | --- |
| Одежда | Полный состав, фактуру/толщину, подкладку, фурнитуру, швы, реальные мерки |
| Обувь | Полный SKU/цвет; ярлыки обеих полупар и коробки; подошву, следы носки и комплект |
| Продавец | Связь с брендом/авторизацию, историю, ассортимент, ответы по товару, возврат и сохранение заказа на площадке |
| Отзывы | Свежие отзывы именно товара/варианта, фото/видео, дополнения, текст отрицательных отзывов и повторяющиеся проблемы |
| Метрики | 评价 товара и 店铺评价 магазина; 粉丝, 月销, повторные покупатели, корзины и отзывы — разные показатели |

Проверять противоречия между заголовком, фото, описанием и выбранным вариантом до оплаты. Не выводить надёжность из одного рейтинга или универсального порога звёзд. Tmall содержит [разные типы магазинов](https://developer.alibaba.com/docs/doc.htm?articleId=120792&docType=1&treeId=583); надпись 旗舰店 не заменяет подтверждения со стороны бренда. 原单, 尾货, 外贸, срезанная бирка, закрытый логотип, низкая цена и обещание «та же фабрика» также не удостоверяют происхождение: [контрпример с поддельным товаром](https://www.pazjw.gov.cn/shuoan/202601/t20260108_31444787.shtml).

К каждому кандидату присвоить понятный статус: **подтверждён официальный/авторизованный канал**; **заказ с предусмотренной платформой проверкой**; **заявление продавца об оригинале/экспорте без независимого подтверждения**; **прямо заявленный аналог/реплика**. Подтверждение канала не освобождает от проверки конкретной вещи; производство бренда в Китае не доказывает связь стороннего объявления с ним. Отсутствие авторизации перепродавца само по себе также не доказывает подделку.

Сохранить модель/SKU/цвет, площадку, название/ID магазина, URL, выбранный размер, цену, доказательства происхождения, возврат и дату проверки. Недоступную карточку, неустановленное наличие или доставку обозначить кандидатом. Затем перейти к [размеру, выкупу, QC и полной стоимости](purchase-and-qc.md). В личную базу покупок добавлять фактическую посадку, ткань, дефекты и результат возврата — эти наблюдения помогают следующему выбору.
